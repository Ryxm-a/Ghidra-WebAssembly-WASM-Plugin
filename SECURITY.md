# Security Policy

This extension processes untrusted WebAssembly modules as reverse-engineering input.

If a crafted module causes unintended host-side behavior beyond an ordinary parser/analyzer failure, please report it privately through GitHub's security-reporting facilities when available.

Ordinary crashes, unsupported instructions, incorrect disassembly/decompilation and analysis bugs may be filed publicly.

Never attach confidential or proprietary binaries to a public report. Prefer a minimal synthetic reproducer.
